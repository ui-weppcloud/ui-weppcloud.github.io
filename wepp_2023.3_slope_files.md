# WEPP Slope File Format (Version 2023.3)

This document describes the format of the WEPP (Water Erosion Prediction Project) slope file for version 2023.3, as used for hydrologic modeling. The parameters and their variable names are defined to assist hydrologists in interpreting the slope files. The structure is explained line by line to clarify the role of each parameter.

## File Structure

The slope file is a text-based format with the following line-by-line structure:

1. **Line 1: `version`**  
   - **Parameter**: `version`  
   - **Description**: Specifies the version of the slope file format, set to `2023.3` for this specification.  

2. **Line 2: `nofes`**  
   - **Parameter**: `nofes`  
   - **Description**: An integer representing the number of overland flow elements, indicating the count of distinct flow segments on the hillslope.  

3. **Line 3: `aspect width elevation`**  
   - **Parameters**:  
     - `aspect`: The direction the hillslope faces, measured in degrees (e.g., 180 for south-facing).  
     - `width`: The abstracted width of the hillslope, in meters, representing the lateral extent of the slope.  
     - `elevation`: The elevation at the bottom of the hillslope, in meters, serving as the reference elevation for the slope profile.  
   - **Description**: These three parameters are written on a single line, separated by spaces, describing the hillslope’s orientation, width, and base elevation.  

4. **Line 4: `npts length`**  
   - **Parameters**:  
     - `npts`: An integer specifying the number of points used to define the slope profile.  
     - `length`: The total length of the hillslope, in meters, used to normalize the distance coordinates in the slope profile.  
   - **Description**: This line contains two values separated by a space, indicating the number of slope points and the hillslope’s total length.  

5. **Line 5: Slope Profile Coordinates (`x, dy` pairs)**  
   - **Parameters**:  
     - `x`: The normalized distance along the hillslope, ranging from 0.0 (start) to 1.0 (end).  
     - `dy`: The slope at the corresponding `x` point, expressed as a fraction (e.g., 0.1 for a 10% slope, not in percent).  
   - **Description**: This line contains a series of `x, dy` pairs, each pair representing a point in the slope profile. The pairs are space-separated, with each pair consisting of an `x` value followed by a `dy` value (e.g., `0.0 0.05 0.5 0.1 1.0 0.15` for three points).  

## Parameter Definitions

- **version**: Identifies the file format version (`2023.3`).  
- **nofes**: Integer specifying the number of overland flow elements.  
- **aspect**: Numeric value (degrees) indicating the hillslope’s orientation.  
- **width**: Numeric value (meters) for the abstracted width of the hillslope.  
- **elevation**: Numeric value (meters) for the elevation at the base of the hillslope.  
- **npts**: Integer specifying the number of points in the slope profile.  
- **length**: Numeric value (meters) for the total hillslope length.  
- **x, dy**: Pairs of numeric values defining the slope profile, where `x` is the normalized distance (0.0 to 1.0) and `dy` is the slope (fraction).

## Example File

An example WEPP slope file for version 2023.3:

```
2023.3
2
180.0 10.0 500.0
3 100.0
0.0 0.05 0.5 0.1 1.0 0.15
```

- **Line 1**: `version` = `2023.3`  
- **Line 2**: `nofes` = `2` (two overland flow elements)  
- **Line 3**: `aspect` = `180.0` degrees, `width` = `10.0` meters, `elevation` = `500.0` meters  
- **Line 4**: `npts` = `3` (three slope points), `length` = `100.0` meters  
- **Line 5**: Three `x, dy` pairs: `(0.0, 0.05)`, `(0.5, 0.1)`, `(1.0, 0.15)`.

## Notes

- The `x` values in the slope profile are normalized (0.0 to 1.0) relative to the `length` of the hillslope.  
- The `dy` values represent slopes as fractions, not percentages (e.g., a `dy` of 0.1 corresponds to a 10% slope).  
- The file is structured for easy parsing by WEPP software, with parameters in a fixed order.  
- Hydrologists can use these parameters to understand the hillslope’s geometry and flow characteristics for erosion and runoff modeling.
