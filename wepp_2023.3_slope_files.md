# WEPP 2023.3 Slope File Format

**Overview**  
The slope file describes each overland‐flow element (hillslope) in a watershed model. It defines the orientation, size, elevation, and detailed slope profile of every hillslope.

## File Structure

1. **Number of Hillslopes**  
   The first line is a single integer: the total count of hillslope elements.

2. **Hillslope Records**  
   For each hillslope, three lines follow:

   - **Line 1:** Aspect, Width, Elevation, Order  
     - **Aspect:** Direction of the hillslope (degrees, 0–360)  
     - **Width:** Hillslope width in meters  
     - **Elevation:** Elevation at the base of the hillslope (m)  
     - **Order:** Hierarchical index within the watershed network  

   - **Line 2:** Number of Profile Points, Total Length  
     - **Number of Profile Points:** How many distance-slope pairs define the profile  
     - **Total Length:** Full hillslope length in meters  

   - **Line 3:** Slope Profile Points  
     A space-separated list of pairs:  
     - **Normalized Distance:** Position along the hillslope, scaled from 0 (top) to 1 (bottom)  
     - **Slope Fraction:** Local slope (rise/run) at that point
